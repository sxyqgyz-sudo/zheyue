# 哲阅 ZheYue

哲阅是面向中国大陆免费提供的 HarmonyOS 本地电子书阅读器，支持 TXT、EPUB、MOBI、AZW3 和 PDF。书籍由用户通过系统文件选择器打开或导入，应用在设备本地管理书架、阅读位置、书签、标注和设置。
